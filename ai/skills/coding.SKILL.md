# 🛠️ Coding Skill (Mastery)

## 🎯 Capability Overview
Advanced capability to design, implement, and optimize software components across the full stack. Focuses on producing code that is not just "functional" but also maintainable, scalable, and type-safe.

## 🧱 Tech Stack Mastery
- **Frontend**: Expert in React 18+, TypeScript, and Vite. Advanced usage of Zustand for state and TanStack Query for server-side state.

- **Styling**: Mastery of TailwindCSS and responsive design principles.

## 💎 Engineering Principles
- **Clean Code**: Adherence to DRY (Don't Repeat Yourself) and KISS (Keep It Simple, Stupid).

- **Design Patterns**: Proficiency in Singleton, Factory, Repository, and Observer patterns.
- **Type Safety**: Zero `any` policy. Comprehensive use of Interfaces, Types, and Zod schemas for E2E validation.
